# Car Rental Web App

A full-stack Car Rental Web Application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).

## 🚀 Features
- **User Authentication:** Secure login and registration for users and car owners.
- **Browse & Search Cars:** View available cars for rent.
- **Book a Car:** Easy and intuitive car booking process.
- **Admin/Owner Dashboard:** Manage car listings, view bookings, and handle operations.
- **Responsive Design:** Optimized for both desktop and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
